# Petfinder Portal

Next.js web portal and dashboards (user, shelter/owner, admin, super admin) for Petfinder.

Setup, environment variables and architecture are documented in the [root README](../README.md). Delivery status is tracked in [docs/plan.md](../docs/plan.md).

```bash
npm install --legacy-peer-deps
cp .env.example .env
npm run dev
```
